# Creator Checklists

[← Course Home](../README.md)

## Pre-Production Checklist

- [ ] Target viewer is clear
- [ ] Core promise is specific
- [ ] Working title exists
- [ ] Thumbnail concept exists
- [ ] Research brief is complete
- [ ] Important claims are marked for verification
- [ ] Script has a strong opening
- [ ] Visual plan exists
- [ ] Required assets are identified

## Recording Checklist

- [ ] Audio is clean
- [ ] Camera / screen recording is framed correctly
- [ ] Notifications are disabled
- [ ] Script or outline is ready
- [ ] Standalone clip moments are delivered clearly
- [ ] Important demonstrations are captured
- [ ] Backup copy is created

## Editing Checklist

- [ ] Opening gets to the point quickly
- [ ] Repeated ideas are removed
- [ ] Captions are accurate
- [ ] Names and numbers are correct
- [ ] Visuals match narration
- [ ] Music does not overpower speech
- [ ] Branding is consistent
- [ ] Asset rights are documented
- [ ] Final video has been watched from start to finish

## Short-Form Repurposing Checklist

- [ ] Clip makes sense without original context
- [ ] Hook works as a standalone opening
- [ ] Vertical framing is correct
- [ ] Captions are readable on mobile
- [ ] Important content avoids platform UI areas
- [ ] Clip has a clear payoff
- [ ] CTA fits the target platform
- [ ] Final clip was manually reviewed

## Publishing Checklist

- [ ] Final title approved
- [ ] Thumbnail / cover approved
- [ ] Description or caption checked
- [ ] Links tested
- [ ] Affiliate disclosure included when required
- [ ] Sponsorship disclosure included when required
- [ ] Rights / licensing checked
- [ ] Correct account selected
- [ ] Correct platform version uploaded
- [ ] Publish/schedule date checked

## Weekly Analytics Checklist

- [ ] Review top performers
- [ ] Review weak performers
- [ ] Identify best topics
- [ ] Identify best hooks
- [ ] Check retention patterns
- [ ] Review comments and audience questions
- [ ] Note subscriber/follower changes
- [ ] Review revenue where relevant
- [ ] Choose one thing to repeat
- [ ] Choose one experiment for next week

## Automation Safety Checklist

- [ ] Workflow has a human approval gate before publishing
- [ ] Generated factual claims are verified
- [ ] AI-generated captions are reviewed
- [ ] Automated crops are reviewed
- [ ] File names are predictable
- [ ] Backups exist
- [ ] Account permissions are limited appropriately
- [ ] Failed automation has a recovery procedure
- [ ] Sponsorship and affiliate disclosures cannot be skipped

# AI Creator Prompt Library

[← Course Home](../README.md)

Use these as starting points. Replace the bracketed fields and adapt them to your channel.

## 1. Niche Research Prompt

```text
I am building a content channel for [AUDIENCE].
The broad niche is [NICHE].

Help me identify:
1. 5 recurring audience problems
2. 5 recurring desires
3. 5 content pillars
4. 10 repeatable video formats
5. 30 video ideas

Prioritize ideas that can be demonstrated, explained, compared, tested, or turned into a series.
Avoid generic motivation and vague topics.
```

## 2. Research Brief Prompt

```text
Create a research brief for a video.

TOPIC: [TOPIC]
TARGET VIEWER: [AUDIENCE]
ANGLE: [ANGLE]
GOAL: [OUTCOME]

Return:
- Main question
- Important sub-questions
- Claims that require verification
- Useful examples
- Counterpoints or limitations
- Terms the viewer may not understand
- A recommended research structure

Do not invent sources or facts.
```

## 3. Hook Generator

```text
Generate 20 opening hooks for a video about [TOPIC].
Target viewer: [AUDIENCE]
Promise: [PROMISE]

Create 4 each in these styles:
- curiosity
- problem-first
- result-first
- contrarian
- demonstration

Keep them concise and avoid fake urgency or promises the video cannot satisfy.
```

## 4. Short-Form Script Prompt

```text
Write a spoken short-form video script.

TOPIC: [TOPIC]
AUDIENCE: [AUDIENCE]
TARGET LENGTH: [LENGTH]
CORE PROMISE: [PROMISE]

Structure:
HOOK
CONTEXT
VALUE
EXAMPLE / PROOF
PAYOFF
CTA

Use short natural sentences.
No long intro.
No generic motivational filler.
Make the script understandable without prior context.
Mark places where a visual, screenshot, B-roll shot, chart, or on-screen text would help.
```

## 5. Long-Form Script Prompt

```text
Create a long-form spoken video script.

AUDIENCE: [AUDIENCE]
TOPIC: [TOPIC]
ANGLE: [ANGLE]
TARGET LENGTH: [LENGTH]
GOAL: [GOAL]

Deliver:
1. 10 hook options
2. Recommended hook
3. Outline
4. Full script
5. Visual suggestions
6. Claims to fact-check
7. 5 title ideas
8. 5 short-form clip opportunities

Keep the language conversational, specific, and easy to say aloud.
```

## 6. Tighten a Script

```text
Tighten this spoken script by approximately 20%.

Remove:
- repeated ideas
- filler
- throat-clearing
- unnecessary transitions
- generic statements

Keep:
- useful facts
- examples
- personality
- the original meaning

Return the revised script plus a short list of what you removed.

[PASTE SCRIPT]
```

## 7. Retention Audit

```text
Audit this video script for audience retention.

Identify:
- slow opening
- repeated ideas
- confusing sections
- sections that are too abstract
- places where a visual change would help
- weak transitions
- weak payoff

For every problem, suggest a specific fix.
Do not add fake suspense.

SCRIPT:
[PASTE SCRIPT]
```

## 8. Visual Shot List

```text
Turn this script into a production shot list.

For every major sentence or idea, provide:
- visual type
- suggested footage or graphic
- on-screen text if useful
- whether it can be reused as a short-form moment

Use these visual categories:
presenter, screen recording, B-roll, screenshot, chart, diagram, generated visual, text animation, product demonstration.

SCRIPT:
[PASTE SCRIPT]
```

## 9. Title Generator

```text
Generate 20 YouTube title ideas.

TOPIC: [TOPIC]
AUDIENCE: [AUDIENCE]
VIDEO PROMISE: [PROMISE]

Group them into:
- direct / searchable
- curiosity
- comparison
- problem / solution
- experiment / story

Do not use misleading clickbait.
```

## 10. Thumbnail Brief

```text
Create 5 thumbnail concepts for this video.

TITLE: [TITLE]
VIDEO PROMISE: [PROMISE]
AUDIENCE: [AUDIENCE]

For each concept provide:
- main visual
- focal point
- emotion or tension
- text, only if necessary
- what information the thumbnail adds beyond the title

Keep each concept understandable at small size.
```

For each clip provide:
- opening line
- ending line
- core idea
- why it can stand alone
- suggested hook rewrite if needed
- target platform

Reject moments that require too much context from earlier in the video.

# Module 4 — AI Video Creation

## Goal

Choose the right production model for your channel and turn finished scripts into videos without overcomplicating the tool stack.

## 1. Choose a Production Model

Most AI-assisted channels use one or more of these models:

### Talking-head
You or a presenter appears on camera. AI helps with scripting, cleanup, captions, reframing, and repurposing.

### Faceless narration
A voiceover drives the video while B-roll, screenshots, graphics, stock media, animations, or generated visuals support the narration.

### Screen-recorded tutorial
The main footage is a software demo, walkthrough, presentation, website, or process.

### Text-to-video / image-to-video
Generated visuals form part or all of the video. This works best when the visuals serve the story rather than existing only because they look impressive.

### Hybrid
Combine real footage, screen recordings, generated assets, stock footage, graphics, and AI-assisted editing.

For most beginners, hybrid production gives the best balance of speed and control.

## 2. Build From the Script

Turn the script into a production table before editing.

```text
SCRIPT LINE | VISUAL | AUDIO | TEXT | SOURCE | STATUS
```

For each line, choose a visual type:

- Presenter
- Screen recording
- B-roll
- Screenshot
- Diagram
- Photo
- Text animation
- Generated image/video
- Chart
- Product demonstration

This prevents the common mistake of generating random visuals after the script is finished.

## 3. Create a Visual Rhythm

A video does not need constant cuts, but the viewer should regularly receive new information visually.

Change the screen when:

- A new idea starts
- A claim needs proof
- A product or interface is mentioned
- A number deserves emphasis
- A comparison is made
- A story changes location or time
- A visual demonstration would explain faster than narration

Do not add movement purely to create noise.

## 4. Source Media Responsibly

Keep track of where every asset came from.

For every video, save:

```text
ASSET NAME
SOURCE
LICENSE / PERMISSION
CREATOR CREDIT IF REQUIRED
DATE ACQUIRED
PROJECT USED IN
```

Do not assume that something found online is free to reuse.

## 5. Create a Reusable Editing System

Before automating editing, define your channel style.

Choose:

- Primary aspect ratios
- Caption style
- Font hierarchy
- Logo placement
- Intro policy
- Transition rules
- Music approach
- B-roll style
- On-screen text rules
- CTA style

The goal is consistency, not complexity.

## 6. Produce the Source Video for Repurposing

If short-form distribution matters, create the source video with clipping in mind.

Use:

- Clean audio
- Clear section breaks
- Standalone explanations
- Strong mini-hooks inside long videos
- Direct statements instead of constant references to earlier sections
- Enough framing room for vertical crops when possible

## 7. AI-Assisted Clipping

After you have a strong source video, an AI clipping tool can reduce the time spent searching manually for reusable moments.

### Practice Workflow

1. Upload a source video you have permission to use.
2. Generate candidate clips.
3. Review the selected moments.
4. Fix captions and names.
5. Check that each clip still makes sense outside the long-form context.
6. Adjust framing where needed.
7. Export only the clips that meet your quality standard.

## 8. The Human Quality Gate

Never publish automatically just because a render completed.

Check:

- Is the first second understandable?
- Are captions correct?
- Are names and numbers correct?
- Does the visual match the narration?
- Is anything cropped incorrectly?
- Is the clip misleading without context?
- Is the audio balanced?
- Are you allowed to use every asset?
- Does the ending feel intentional?

## 9. Build a Production Folder Template

Use a repeatable structure:

```text
VIDEO-001/
├── research/
├── script/
├── source-footage/
├── audio/
├── graphics/
├── generated-assets/
├── project-files/
├── exports/
│   ├── long-form/
│   └── shorts/
└── publishing/
```

This becomes increasingly important once you batch or outsource work.

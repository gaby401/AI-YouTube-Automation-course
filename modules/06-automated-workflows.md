# Module 6 — Building the Automation Workflow

[← Module 5](05-voice-music-assets.md) | [Course Home](../README.md) | [Next: Module 7 →](07-youtube-automation.md)

## Goal

Connect your content stages into a repeatable production system that reduces manual effort without removing quality control.

## 1. Map the Workflow Before Automating It

Write the entire process from idea to published video.

Example:

```text
IDEA BANK
  ↓
RESEARCH BRIEF
  ↓
SCRIPT
  ↓
RECORD / GENERATE SOURCE VIDEO
  ↓
EDIT
  ↓
CLIP / REFRAME / CAPTION
  ↓
QUALITY REVIEW
  ↓
PUBLISH
  ↓
ANALYTICS
  ↓
LESSONS BACK INTO IDEA BANK
```

If a workflow is confusing manually, automation usually makes the confusion faster.

## 2. Identify Bottlenecks

Track how long each stage takes for three videos.

Use:

```text
TASK | TIME | REPEATED? | ERROR-PRONE? | AUTOMATION CANDIDATE?
```

Automate the tasks that are both repetitive and expensive in time.

## 3. Separate Creative Decisions From Mechanical Tasks

### Creative decisions

- Choosing the topic
- Selecting the angle
- Approving the hook
- Deciding what stays in the edit
- Choosing the final thumbnail or title

### Mechanical tasks

- Creating folders
- Copying metadata templates
- Transcribing footage
- Reformatting aspect ratios
- Generating first-pass captions
- Export naming
- Updating production status

Mechanical tasks are usually safer automation targets.

## 4. Use Status Gates

Do not let content flow straight from generation to publishing.

A basic status system:

```text
IDEA
RESEARCHING
SCRIPTING
READY TO RECORD
EDITING
READY FOR REVIEW
APPROVED
SCHEDULED
PUBLISHED
REVIEWED
```

Automation can move files or create tasks, but only an approved item should enter the publishing stage.

## 5. Build Templates

Create templates for:

- Research briefs
- AI prompts
- Script structure
- Video folders
- Descriptions
- Publishing checklists
- Thumbnail briefs
- Clip review sheets
- Weekly analytics reviews

Templates are often the highest-value form of automation because they are simple and reliable.

## 6. One-to-Many Repurposing

A scalable workflow often begins with one high-quality source asset.

```text
1 long video
   ↓
3–10 candidate short clips
   ↓
platform-specific edits
   ↓
YouTube Shorts / TikTok / Reels
```

## 7. Naming Convention

Use predictable file names.

Example:

```text
2026-08-19_ai-editing_source_v01.mp4
2026-08-19_ai-editing_short-01_v02.mp4
2026-08-19_ai-editing_thumbnail_v03.png
```

A naming convention makes automation and collaboration much easier.

## 8. Build a Production Database

You can begin with a spreadsheet, database, or simple Markdown table.

Recommended fields:

```text
ID
TITLE
PILLAR
PLATFORM
STATUS
SCRIPT LINK
SOURCE VIDEO
CLIPS CREATED
PUBLISH DATE
VIEWS
WATCH TIME / RETENTION
CTR IF AVAILABLE
NOTES
NEXT ITERATION
```

## 9. The Feedback Loop

Automation becomes powerful when analytics affect the next batch.

Every week ask:

1. Which topics received the strongest response?
2. Which hooks retained attention?
3. Which clips underperformed?
4. Which formats were easiest to produce?
5. Which videos created comments, shares, or subscribers?
6. What should we repeat?
7. What should we stop doing?

Then update your templates and idea bank.

## 10. Reliability Before Complexity

Do not judge your system by how impressive the automation diagram looks.

Judge it by:

- How often it works correctly
- How quickly errors are found
- Whether assets remain organized
- Whether content quality stays consistent
- Whether the system saves time
- Whether performance improves

## Module Assignment

Build your first end-to-end production board and run three pieces of content through it.

For each step, record:

```text
MANUAL / AI-ASSISTED / AUTOMATED:
TOOL USED:
TIME SPENT:
ERRORS FOUND:
REVIEW REQUIRED:
NEXT IMPROVEMENT:
```

After three videos, automate or template the single most repetitive bottleneck.

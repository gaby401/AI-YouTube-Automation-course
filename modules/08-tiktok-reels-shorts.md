# Module 8 — TikTok, Reels & Shorts

[← Module 7](07-youtube-automation.md) | [Course Home](../README.md) | [Next: Module 9 →](09-monetization.md)

## Goal

Adapt your content engine to vertical short-form platforms without treating every platform as identical.

## 1. Start With the Core Idea

A short video should usually communicate one primary idea.

Before editing, write:

```text
HOOK:
ONE CORE IDEA:
PAYOFF:
NEXT ACTION:
```

If you need five paragraphs to explain what the clip is about, the clip is probably trying to do too much.

## 2. Design for the First Seconds

Short-form viewers decide quickly whether to continue.

Useful openings include:

- Start with the result
- Ask a sharp question
- Show a surprising visual
- State the mistake
- Begin in the middle of the action
- Make a specific promise

Avoid wasting the opening on logos or long introductions.

## 3. Remove Context Dependence

Repurposed clips often fail because they rely on the original long-form video.

Fix phrases like:

> "Like I said earlier..."

or

> "The second thing is..."

If the viewer has no idea what came before, rewrite or trim the clip so it stands alone.

## 4. Reframe for Vertical Viewing

Vertical content should keep the important subject visible and readable.

Review:

- Face or subject framing
- Screen recordings
- Text size
- Captions
- Product demonstrations
- Split-screen layouts
- Platform interface safe areas

Automated reframing can save time, but always review the crop manually.

## 5. Caption for Mobile

Keep captions easy to read on a phone.

Check:

- Short line lengths
- Accurate timing
- Correct names
- Large enough text
- Contrast
- Placement away from UI controls

## 6. Create Platform Variants

Do not assume the exact same export is ideal everywhere.

Create a master short, then adapt:

```text
MASTER CLIP
├── YouTube Shorts version
├── TikTok version
└── Instagram Reels version
```

Possible differences include caption copy, music, CTA, description, hashtags, cover frame, and clip duration.

## 8. Build a Short-Form Content Mix

A healthy content engine can include:

- Educational clips
- Opinions
- Stories
- Quick demonstrations
- Mistakes
- Comparisons
- Behind-the-scenes moments
- Responses to audience questions

Avoid making every video the same formula with different nouns swapped in.

## 9. Build a Testing Log

For each short, track:

```text
HOOK TYPE:
TOPIC:
FORMAT:
DURATION:
PLATFORM:
VIEWER RESPONSE:
RETENTION SIGNAL:
COMMENTS:
SHARES:
FOLLOW/SUBSCRIBE RESULT:
LESSON:
```

Over time, you will discover which combinations work best for your audience.

## 10. Repurpose Intelligently

One long-form video does not automatically deserve ten Shorts.

Publish only the moments that:

- Have a clear point
- Make sense independently
- Begin strongly
- Deliver a payoff
- Match your channel
- Are worth the viewer's time

Quality should control volume.

## Module Assignment

Take one source video and create three short-form variants.

For each clip:

1. Rewrite the opening if necessary.
2. Check vertical framing.
3. Correct captions.
4. Create a platform-specific caption/description.
5. Record what you expect the clip to achieve.
6. Add the result to your testing log after publishing.

## Completion Check

You are ready for Module 9 when you can repurpose content efficiently while still making deliberate platform-specific decisions.

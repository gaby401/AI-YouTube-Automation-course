# TikTok Strategy Guide

[← Course Home](../README.md)

## Goal

Build a repeatable TikTok workflow around strong openings, single-idea videos, native-feeling edits, and rapid testing.

## Start With One Idea

Write:

```text
HOOK:
CORE IDEA:
PROOF / EXAMPLE:
PAYOFF:
CTA:
```

Short-form becomes confusing when several ideas compete for attention.

## Hook Types to Test

- Problem-first
- Result-first
- Question
- Contrarian statement
- Visual demonstration
- Mistake
- Story opening
- Comparison

Do not use a hook that the rest of the video cannot satisfy.

## Edit for Mobile

Check:

- Subject remains visible in vertical format
- Captions are readable
- Important text avoids interface overlays
- Screen recordings are zoomed enough to understand
- The first frame communicates something useful

## Repurpose With Context

When clipping long-form content, remove references that depend on earlier sections.

A good TikTok clip should usually stand on its own.

## Build Series

Repeatable series can reduce idea fatigue.

Examples:

- "One AI tool in 30 seconds"
- "Automation mistake #___"
- "I tested ___ so you don't have to"
- "Fix your workflow: part ___"

## Test Variables

Track one variable at a time where possible:

```text
HOOK STYLE:
DURATION:
TOPIC:
FORMAT:
CAPTION STYLE:
CTA:
RESULT:
```

## Do Not Automate Blind Publishing

Before every post, check:

- Accuracy
- Context
- Captions
- Rights
- Disclosure requirements
- Visual crop
- CTA
